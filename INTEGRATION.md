# Premium Bar - встраивание в iframe

## Готовый архив
- `index.html` - только содержимое баннера, **без** `min-height:100%` и `justify-content:flex-end`; при самостоятельном открытии баннер располагается сверху, не за пределами мобильного экрана.
- `index.js` - четыре состояния, автосхлоп через 3 секунды и свайп вверх непосредственно по баннеру на мобильном.
- `demo.html` - отдельная тестовая страница, закрепляет iframe внизу окна и показывает прокрутку родительской страницы. Открывать через локальный HTTP-сервер (а не file://).

## Поведение
1. Загружается **раскрытым** (desktop/mobile).
2. Через 3000 мс схлопывается **в демо-режиме**.
3. На десктопе после этого работает hover (в демо-режиме).
4. На мобильном свайп **вверх непосредственно по баннеру** вызывает раскрытие.
5. Прокрутка/свайп **на самой странице сайта** НЕ доступен коду внутри iframe. Сайт обязан слушать этот жест/прокрутку и отправлять `premiumbar-expand` при возврате вверх, `premiumbar-collapse` при нужном движении вниз.
6. Для встроенного production-режима родитель включает `premiumbar-set-mode` с `mode:host` - это отключает демо-таймер и локальный desktop hover. При необходимости сохранения автоматического схлопа через 3 секунды продакшен-сайт должен сам отправить команду через 3 секунды, а не включать этот режим сразу.

## Команды сайта
```js
const frame = document.querySelector('#premium-bar-iframe');
frame.contentWindow.postMessage({type:'premiumbar-expand'}, '*');
frame.contentWindow.postMessage({type:'premiumbar-collapse'}, '*');
frame.contentWindow.postMessage({type:'premiumbar-set-mode', mode:'host'}, '*');
```

После загрузки 200px высоты iframe должны быть доступны для раскрытого состояния. Не уменьшайте iframe по высоте раньше, чем закончится переход, иначе часть креатива обрежется. Баннер отправляет `premiumbar-resize` и `premiumbar-state`. Максимальная высота 200px. В parent-пейдже позиционирование sticky/fixed и отступ под баннер задает разработчик.

**Безопасность:** заменить `'*'` на проверенный origin сайта и валидировать `event.origin` в обработчиках сообщений на боевой странице.


## Исправления v3
- `index.html`: содержимое закреплено внизу собственного слота 200 px через flex-end. Именно это исключает пустое пространство ПОД свернутым баннером внутри iframe.
- `demo.html`: fixed-контейнер 200 px, скролл обрабатывается в родительской странице; изменение состояния по накопленным 42 px движения в одну сторону, чтобы снизить дрожание. Первые 3 секунды баннер раскрыт.
- `index.js`: desktop hover работает и в host mode; после ухода указателя возвращается состояние от скролла страницы. Мобильный свайп вверх непосредственно по креативу раскрывает его.
- Во время интеграции iframe должен оставаться высотой 200 px (и иметь `bottom:0` на сайте). Высота самого креатива изменяется внутри этого слота. Не используйте `premiumbar-resize`, чтобы динамически уменьшать iframe до 80/100 px, иначе баннер будет скакать и может обрезаться.
- Для свайпов ВНЕ iframe разработчики должны отправлять `premiumbar-expand` или `premiumbar-collapse` из родительской страницы.
